## How to ask AI for help

Use AI as a tutor. A useful request names your attempt and asks for one level of help:

```text
I am a beginner. Here is my code and the exact error.
Do not give me the finished solution yet.
Explain the error in plain language and give me one hint.
Then ask me to predict what the fix changes.
```

If the hint does not unblock you after 20 minutes, ask for a smaller example. Type the final code yourself and explain it aloud.
