# Week 1 checkpoint

Answer without notes. Write the answers below each question or in your weekly notes.

1. What is the difference between source code and a running program?
2. What does a variable name do?
3. Why does `const sharePrice: number = "100"` fail?
4. What is the difference between a relative path and an absolute path?
5. What does `git add` do? What does it not do?
6. What does a Git commit contain?
7. Why should the program calculate total value instead of storing the final total?
8. In this course, what is the difference between a Fund Share and a Share Token?
9. Name two facts about the fictional Treasury Fund that the blockchain does not prove.
10. If your program fails, what four pieces of information should you collect before asking for help?

## Practical check

Starting from a blank file, write a program that:

- stores a fund name, ticker, share count, and price per share;
- calculates the total value;
- uses a function to format one output sentence;
- prints the result.

You pass when the program runs and you can explain every line. Speed does not matter in Week 1.
